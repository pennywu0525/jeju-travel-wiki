# 濟州島自駕遊攻略》濟州島自駕租車/駕照/導航/停車/加油方式一次看



## 來源摘要
商業旅遊平台的實務整理，已讀取租車、驗車、還車、加油、導航及分區景點段。日期未在讀取內容中辨識，不以搜尋爬取日代替發布日。

## 萃取重點（實務建議，非法律）
- 取還車拍攝既有損傷，檢查輪胎、燈光、雨刷、油量和導航；閱讀合約及結算單。
- 使用 Naver Map 找目的地及加油站；不熟悉機台可請站員協助。
- 停車前確認收費方式；油量依租約，LOTTE 的具體要求另見 SRC-05。
- 西部景點舉例：涯月咖啡街、挾才海邊；東部：城山日出峰、涉地可支；南部：柱狀節理、正房瀑布。

## 衝突與排除
- 右轉段缺先停車要求：以 [SRC-04](SRC-04.md) 的警察廳說明取代。
- 「只認黃色油槍」「僅有兩種油」不採用；不能推論任一租用車的油種。
- 路邊線色即准停、城山停車免費、WOWPASS 通用及概括速限，均未取得適用官方支持，列待查證，不進簡報。
- 「不會踩雷」「容易開」是主觀評價。電話號碼導航法與 App 特定功能未實測。
